Requirements:

Protect All Routes: Ensure no unauthenticated user can access any route except public ones like /login, /signup, and /not-found. Redirect unauthenticated users to /login.
Security Best Practices:
Use HTTP-only, Secure, SameSite=Strict cookies for storing JWT tokens (via js-cookie; avoid localStorage to prevent XSS).
Validate tokens on the client-side minimally (e.g., check expiration with jwt-decode), but rely on server-side verification for all API calls.
Implement token refresh if expired (assume /api/auth/refresh endpoint).
Prevent common vulnerabilities: Use React's built-in escaping, validate inputs with Zod or similar in forms, use CSP headers via Next.js headers().
Handle edge cases: Logout clears state and cookies, session persistence across refreshes, loading states to avoid flashes of unprotected content.
Follow OWASP guidelines for auth: Secure password handling (hashing on backend), rate limiting on login (note for backend), MFA optional.

Next.js Best Practices:
Use Middleware (/middleware.ts) for server-side auth checks on all protected routes (e.g., check cookie token and verify with backend before rendering; exclude /login, /signup, /api/*, /not-found).
For client-side, wrap protected components in an AuthGuard HOC or context provider that redirects to /login if not authenticated.
Use Server Components where possible for initial auth checks, falling back to Client Components for interactive parts (e.g., forms).
Optimize for SSR/SSG: Fetch user data in server components using cookies.
Add a custom not-found page at /app/not-found.tsx for 404 handling.

Zustand Best Practices:
Create an auth store (/stores/authStore.ts) with persist middleware to sync with cookies (use zustand/middleware and a cookie storage adapter).
States: user (object or null), token (string or null), isAuthenticated (boolean), isLoading (boolean), error (string or null).
Actions: login (async: call API, set token/user), signup (async: call register API, then auto-login), logout (clear all), verifyToken (async: check validity).
Use hooks like useAuthStore in components.

React.js, Shadcn/UI, and Magic UI Best Practices:
Use hooks like useEffect for initial auth check on mount, useForm from react-hook-form for form handling with Zod validation.

Ensure components are memoized where performance matters.
For UI: Compose pages with shadcn components (Card, Form, Input, Label, Button, Toast via sonner) enhanced with Magic UI animations (e.g., AnimatedGradientText for titles, ShinyButton for submits, Meteors for backgrounds, Confetti for success).
Themes: Use dark/light mode support if configured.
Animations and Smooth Navigation:

Enhance components: Use Magic UI's animated variants for shadcn elements (e.g., animated cards with hover effects, fade-in transitions for forms).
